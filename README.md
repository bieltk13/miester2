# Meister Sorvetes — site one page

Arquivos prontos para publicar como site estático no GitHub Pages.

## Publicar

1. Extraia o ZIP.
2. Envie `index.html`, a pasta `assets/` e este `README.md` para a raiz do repositório.
3. No GitHub, abra **Settings → Pages** e escolha publicar pela branch principal, na pasta raiz.

## O que está incluído

- Logo fornecido pela empresa, em `assets/meister-logo.png`.
- Navegação de página única, menu adaptável para celular, FAQ interativo e botões com mensagens pré-preenchidas do WhatsApp.
- Endereço informado: Travessa Barão do Rio Branco, 604, Cascavel — PR.
